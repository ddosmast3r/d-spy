# Мониторинг отзывов на Яндекс.Картах

Раз в N минут проверяет страницу отзывов организации и присылает в Telegram каждый новый отзыв.

## Как это работает

Яндекс.Карты отдают отзывы прямо в HTML страницы, внутри
`<script type="application/json" class="state-view">`. Капча и исполнение JS не нужны,
одного GET-запроса достаточно. Отдаётся до 50 отзывов на страницу, отсортированных по времени.

Идентификаторы уже показанных отзывов лежат в SQLite (`seen.db`), поэтому перезапуск
не приводит к повторной рассылке.

## Установка

```bash
cd "НОВЫЙ ПРОЕКТ - DSPY"
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Дальше заполнить `.env`:

1. `TELEGRAM_BOT_TOKEN` — токен от @BotFather.
2. Написать своему боту `/start` в Telegram.
3. Выполнить `python whoami.py` и подставить полученный `TELEGRAM_CHAT_ID`.

## Запуск

```bash
python main.py --once --dry-run   # проверить, что отзывы забираются, ничего не отправляя
python main.py --once             # одна проверка с отправкой
python main.py                    # постоянный цикл
```

При первом запуске бот помечает все существующие отзывы прочитанными и ничего не шлёт,
иначе в чат прилетела бы сотня старых. Уведомления начнутся со следующего нового отзыва.

## Кому бот может писать

Только владельцу. `chat_id` берётся из `TELEGRAM_CHAT_ID` и не является параметром функции
отправки: указать другого получателя из кода нельзя. Входящие сообщения бот не читает вообще,
`getUpdates` используется только вручную в `whoami.py`.

## Добавить вторую организацию

`ORGS` в `.env`, через запятую. Id берётся из ссылки `https://yandex.ru/maps/org/<id>/`:

```
ORGS=30239245640:Чё? Шашлык,12345678901:Lovely Bag
```

## Автозапуск (macOS, launchd)

Создать `~/Library/LaunchAgents/ru.reviews.watcher.plist`, указать путь к `.venv/bin/python`
и к `main.py`, затем `launchctl load ~/Library/LaunchAgents/ru.reviews.watcher.plist`.
