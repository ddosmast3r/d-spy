# Расширение Chrome: черновики ответов в Яндекс Бизнесе

Добавляет на страницу Яндекс Бизнеса кнопку «🤖 Черновик». По нажатию расширение
берёт текст отзыва, генерирует ответ через локальную Ollama и вставляет его в поле
ответа. Остаётся нажать «Отправить».

## Важно

Работает **только в домашней сети и при включённом ПК** с Ollama (192.168.0.112).
Вне дома черновиков не будет. Мониторинг отзывов в Telegram от этого не зависит.

## Установка

1. Chrome → `chrome://extensions/`
2. Включить «Режим разработчика» (справа вверху).
3. «Загрузить распакованное расширение» → выбрать эту папку `extension`.
4. Открыть настройки расширения (иконка → шестерёнка, или на странице расширения
   «Детали» → «Параметры расширения»), нажать «Проверить связь». Должно быть
   «Связь есть, модель на месте».

## Использование

1. Открыть отзывы в Яндекс Бизнесе (`yandex.ru/sprav`).
2. Кликнуть в поле ответа под нужным отзывом.
3. Нажать «🤖 Черновик» справа внизу.
4. Проверить текст и нажать «Отправить».

## Настройки

Адрес Ollama, модель и название заведения меняются на странице параметров.
По умолчанию: `http://192.168.0.112:11434`, `gemma4:12b`, `Чё? Шашлык`.

## Как устроено

- `background.js` (сервис-воркер) единственный ходит в Ollama: контент-скрипт не может
  звать `http://` со `https`-страницы (mixed content), а воркер может.
- Правила стиля (`style.js`) проверяются кодом после генерации, не только просьбой к модели.
- Примеры (`examples.js`) это те же 16 реальных ответов с Яндекса, что у бота.
- Селекторов Яндекса нет: текст отзыва берётся эвристикой от поля ответа, поэтому
  расширение переживает перевёрстку кабинета.
